# Tina 游戏设计文档

## 概述

**游戏类型**：2D沙盒挖掘游戏（类《泰拉瑞亚》风格）
**开发语言**：C++20
**技术栈**：SDL3 + bgfx + Box2D v3 + EnTT (ECS)
**最后更新**：2025年

---

## 核心玩法

### 游戏目标
探索程序生成的世界，挖掘地形，建造结构，与液体物理系统交互。

### 玩家角色系统
- **ECS架构**：使用EnTT实现的实体组件系统
- **角色管理**：支持多角色创建和AI控制（当前版本：单玩家角色）
- **角色属性**：
  - 尺寸：0.8×2.0 格
  - 移动速度：8.0 单位/秒
  - 跳跃速度：14.0 单位/秒
  - 空中控制：30% 移动能力

### 移动机制
**泰拉瑞亚式物理**：
- **立即停止**：松开方向键时角色立即停止（无惯性）
- **空中控制**：跳跃时仍可水平移动（30%速度）
- **连续跳跃**：长按跳跃键自动连跳（触地时立即起跳）
- **精确碰撞**：基于AABB的瓦片碰撞检测

**控制方案**：
- `A/D` 或 `方向键左/右`：水平移动
- `W` 或 `空格`：跳跃（长按连跳）
- `鼠标左键`：执行当前工具
- `滚轮` 或 `数字键1-8`：切换工具

## 地形系统

### 程序生成
基于柏林噪声的多层次地形生成：

**1. 生物群系系统**（8种）：
- **海洋**：大片水域
- **海滩**：沙质地带
- **森林**：树木密集
- **平原**：草地+花朵
- **沙漠**：沙+仙人掌
- **苔原**：雪+冰
- **山地**：石头+雪顶
- **沼泽**：粘土+死水

**2. 地形层次**：
- 地表层：生物群系特有材料（草、沙、雪等）
- 次表层：土、粘土
- 深层：石头
- 地下：洞穴系统

**3. 矿物生成**：
- 煤矿（浅层）
- 铁矿（中层）
- 金矿（深层）
- 钻石矿（深层+稀有）

**4. 植被与装饰**：
- 树木（森林/平原）
- 花朵（平原）
- 蘑菇（洞穴/沼泽）
- 水晶（洞穴）
- 草丛装饰

### 瓦片类型
**固体方块**（50+种）：

## 液体物理系统

### 核心特性
- **255级水位深度**：支持部分填充（0-255）
- **元胞自动机**：真实的流体力学模拟
- **真实高度渲染**：水面高度随水位动态变化
- **粒子集成**：爆炸时水转换为物理粒子，沉淀后回归瓦片

### 流动算法
**两阶段更新**（每帧2次迭代）：

**阶段1 - 重力下落**：
```
当前水位 → 尝试向下流动 → 填充下方空间（最大64单位/步）
```

**阶段2 - 水平均衡**：
```
左右水位差 → 流向低水位方（最大32单位/步）
```

**性能优化**：
- 双缓冲机制避免更新冲突
- 差分更新：只重建变化区域
- 奇偶交替打破左右偏置

### 物理力学
碎片粒子在水中受以下作用力：
- **浮力**：抵消85%重力
- **阻力**：与速度相反（系数1.2）
- **流力**：跟随水流方向（系数2.0）

**粒子沉淀条件**：
- 速度低于阈值
- 下方有固体支撑
- 自动转换为瓦片水位

## 粒子系统

### 粒子类型
**爆炸粒子**：
- 数量：260个/次
- 速度：6.0 ~ 14.0 单位/秒（径向散射）
- 尺寸：0.30 ~ 0.90 格
- 生命周期：0.6 ~ 1.6 秒
- 颜色：土黄色（0.78, 0.70, 0.58）

**水粒子**：
- 生成：爆炸水瓦片时（8粒子/格）
- 物理：低密度（0.35）、低摩擦（0.05）、无弹性
- 特性：受浮力影响小，速度降低后沉淀回瓦片

### 物理引擎
- **Box2D v3**：仅用于粒子物理
- **子步数量**：4 步/帧（提升稳定性）
- **粒子上限**：动态管理，超限时FIFO回收
- **边界清理**：超出视野±20格自动销毁

## 渲染系统

### 技术栈
**bgfx**：跨平台图形抽象层
- 自动选择后端（DirectX/Vulkan/OpenGL）
- 多视图渲染管线
- 顶点缓冲池管理

### 渲染管线
**视图分层**（3个视图）：
- **视图1**：固体方块（清屏+深度）
- **视图2**：液体+玩家角色+粒子（透明混合）
- **视图3**：UI文本+工具栏（像素坐标）

**着色器**：
- `color.vs / color.fs`：纯色顶点着色
- 顶点布局：Position(xyz) + Color(rgba)

### 相机系统
**2D正交相机**：
- 平滑跟随：插值系数0.1（避免抖动）
- 视野高度：60格（宽度自适应）
- 边界限制：不超出地图范围

**坐标系统**：
- 世界坐标：1单位 = 1格
- Y轴向上（OpenGL风格）
- 像素坐标：Y轴向下（SDL风格）

## 架构设计

### 模块划分
```
Tina/
├── core/          # 核心工具（日志、时间、容器、内存）
├── os/            # 平台抽象（窗口、事件）
├── renderer/      # 渲染（bgfx封装、着色器管理）
├── ecs/           # 实体组件系统（EnTT）
│   ├── World      # 世界管理器
│   ├── Components # 组件定义
│   └── systems/   # 系统（输入、移动、物理、渲染、AI）
├── game/          # 游戏逻辑（地图、相机、配置）
├── physics/       # 物理（Box2D封装、碎片管理）
├── particles/     # 粒子系统
└── ui/            # UI（文本、工具栏、布局）
```

### ECS组件系统
**组件定义**：
```cpp
struct Transform        { float x, y, rotation; };
struct Velocity         { float vx, vy; };
struct PhysicsBody      { float width, height, gravity; bool onGround; };
struct CharacterController { float moveSpeed, jumpSpeed, airControl; };
struct PlayerController { bool moveLeft, moveRight, jumpHeld; };
struct AIController     { Behavior behavior; };
struct Renderable       { float r, g, b, a; };
```

**系统执行顺序**：
```
1. PlayerInputSystem   // 处理玩家输入
2. AISystem            // AI决策
3. CharacterMovementSystem // 角色移动逻辑
4. PhysicsSystem       // 碰撞检测+重力
5. CharacterRenderSystem // 渲染所有角色
```

### 内存管理
**EASTL容器**：
- `Container::Vector` → `eastl::vector`
- `Container::String` → `eastl::string`
- `Memory::UniquePtr` → `eastl::unique_ptr`

**自定义分配器**：EASTLAlloc（全局内存池）

## 性能指标

### 目标帧率
- **60 FPS**：垂直同步+MSAA×8
- **固定时间步**：物理更新解耦渲染

### 优化策略
1. **差分更新**：只重建变化的液体区域
2. **视锥剔除**：仅渲染相机可见区域
3. **对象池**：粒子FIFO回收
4. **双缓冲**：液体CA并行计算

## 开发规范

### 命名约定
- **类名**：PascalCase（`TileMap`, `PlayerController`）
- **函数名**：camelCase（`update()`, `createCharacter()`）
- **成员变量**：m_前缀（`m_tiles`, `m_world`）
- **常量**：UPPER_CASE（`EXCAVATE_RADIUS`）

### 代码风格
- **缩进**：4空格
- **注释**：简体中文（函数/类级）+ 行尾简短说明
- **日志**：TINA_INFO/WARN/ERROR宏

### 构建系统
- **CMake**：跨平台构建
- **C++20**：requires + concepts + ranges
- **依赖管理**：子模块（SDL3, bgfx, Box2D, EnTT）

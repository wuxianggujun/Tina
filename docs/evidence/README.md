# 验证证据快照

这个目录装的是一次性的验证记录：某个 gate 在某台机器、某个时间点跑出来的结果。它们**不随代码更新**。

## 为什么单独放

这些文件和 `docs/` 根下的模块参考文档性质完全不同。参考文档描述当前应该成立的行为，证据文件描述过去某一刻实际观测到的行为。混在一起时，读者无法一眼分辨手里这份文档是不是还有效。

## 怎么用

**把这里的内容当作历史观测，不要当作当前行为的依据。** 一份证据说某个 gate 通过了，只说明它在记录的那一刻、那台机器上通过了。要确认现在是否仍然通过，重新跑对应的 gate。

这一点在本仓库有过实际代价：文档和头注释描述过代码从未真正达到的意图，也出现过 gate 崩溃却被当成通过的情况（输出里缺少统计行是唯一线索）。判断当前状态时，以实际执行和退出码为准，而不是以这里的记录为准。

## 引用约定

本目录内文件互相引用直接写文件名；引用 `docs/` 根下的文档要加 `../` 前缀，例如 `](../backlog.md)`。`tools/docs/CheckDocs.ps1` 会校验所有本地链接，写错会在 gate 里报错。

# Tina Engine

Tina targets C++23 as its 2D/3D game-engine language baseline and is built around GLFW, bgfx, miniaudio,
EnTT, and a custom retained-mode UI. The current stabilization milestone keeps
the existing 2D sandbox playable, makes the custom UI deterministic, and adds a
minimal 3D smoke scene without replacing bgfx with a custom RHI.

The active design, verified status, and build instructions are maintained in
the [Chinese documentation](README_CN.md).
